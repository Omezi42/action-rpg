# 5. 敵

## 小鬼(M1の唯一の敵)
| 項目 | 値 |
|---|---|
| HP | 3 |
| 接触ダメージ | 1 |
| うろつき速度 | 30px/秒(1〜2秒ごとにランダムな方向へ歩く/止まる) |
| 追跡速度 | 55px/秒 |
| 気づく距離 | 80px(離れる距離 120px で追跡をやめる) |
| 被弾硬直 | 0.3秒 |

- 被弾硬直中は接触ダメージを与えない。理由:斬り抜けた直後に硬直中の敵へ触れて被弾する理不尽を防ぐため
- 敵とプレイヤーは互いにすり抜ける(接触はダメージだけ)。敵は壁・岩には当たる。理由:踏み込みで敵を通過するため
- 試作場には小鬼を3体置く。全滅したら2秒後に同じ位置に3体復活する(手触り確認のため)
- 色違いの派生敵はM1以降で足す
