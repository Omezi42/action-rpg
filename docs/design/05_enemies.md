# 5. 敵

## 種類
| 項目 | 小鬼 | 赤鬼(速いが脆い) | 青鬼(硬くて遅い) |
|---|---|---|---|
| 色 | 黄土(#c8a060) | 赤(#c0504d) | 青(#4d6fc0) |
| HP | 3 | 1 | 8 |
| 接触ダメージ | 1 | 1 | 2 |
| 追跡速度 | 50px/秒 | 90px/秒 | 30px/秒 |
| 被弾硬直 | 0.3秒 | 0.3秒 | 0.3秒 |
| ノックバック | 12px | 12px | 4px |

- 小鬼:構えで足を止めても、狙って当てられる程度の緩慢さ
- 赤鬼:主人公(80px/秒)より速く逃げ切れないので、寄られる前に斬る最優先の的。抜き打ちでも倒れる
- 青鬼:一撃で倒せるのは一閃だけ(参なら2回)。遅いが触れると痛い、道を塞ぐ壁。一閃の通り道に入れる狙いを生むため
- 全種が常にプレイヤーへ直進する
- 被弾硬直中は接触ダメージを与えない。理由:斬り抜けた直後に硬直中の敵へ触れて被弾する理不尽を防ぐため
- 敵とプレイヤーは互いにすり抜ける(接触はダメージだけ)。敵は壁・岩には当たる。理由:踏み込みで敵を通過するため

## 出現(数値は仮置き。試遊して調整する)
| 項目 | 値 |
|---|---|
| 出現位置 | アリーナ外周の壁沿い(画面端から24px内側の周上)のランダムな点。プレイヤーから64px以内には出さない |
| 出現間隔 | 開始時2.0秒 → 制限時間(60秒)で0.4秒まで直線的に縮める。開始直後に1体目 |
| 種類の選び方 | 出現のたびに、出現を始めている種類から重みで抽選する。重みは 小鬼6・赤鬼3・青鬼2 |
| 出現を始める時刻 | 小鬼0秒・赤鬼10秒・青鬼25秒。理由:序盤は小鬼で慣れ、後半ほど「どれから斬るか」の判断を増やすため |
| 同時に出ている上限 | 40体(全種の合計)。上限の間は出現を見送る |
