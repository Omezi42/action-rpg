# 5. 敵

## 種類
| 項目 | 小鬼 | 赤鬼(速いが脆い) | 青鬼(硬くて遅い) | 弓鬼(離れて撃つ) |
|---|---|---|---|---|
| 色 | 黄土(#c8a060) | 赤(#c0504d) | 青(#4d6fc0) | 緑(#5da04d) |
| HP | 3 | 1 | 8 | 2 |
| 接触ダメージ | 1 | 1 | 2 | 1 |
| 追跡速度 | 50px/秒 | 90px/秒 | 30px/秒 | 45px/秒 |
| 被弾硬直 | 0.3秒 | 0.3秒 | 0.3秒 | 0.3秒 |
| ノックバック | 12px | 12px | 4px | 12px |
| 魂(経験値。8章) | 1 | 1 | 3 | 2 |

- 小鬼:構えで足を止めても、狙って当てられる程度の緩慢さ
- 赤鬼:主人公(80px/秒)より速く逃げ切れないので、寄られる前に斬る最優先の的。抜き打ちでも倒れる
- 青鬼:一撃で倒せるのは一閃だけ(参なら2回)。遅いが触れると痛い、道を塞ぐ壁。一閃の通り道に入れる狙いを生むため
- 弓鬼:追跡中に主人公が150px以内に入ったら立ち止まり、0.6秒構えて(弓の向きに線を出す。向きは構えの始めに決める)矢を放つ。
  次の構えまで2.5秒。その間も150px以内なら立ち止まったまま、離れたら追う。理由:足を止めて溜める主人公に「構えている間に撃たれる」圧をかけ、弓鬼から先に斬る判断を生むため
- 矢:毎秒140pxで直進、ダメージ1。主人公に当たる・壁や岩に当たる・300px進むと消える。敵はすり抜ける。踏み込み中は無敵なので当たらない
- 全種が「気づいてから」襲う(下の表)。理由:気づいてから動き出すまでの間で、どの群れから斬るかを選び、溜める余裕を作るため
- 被弾硬直中は接触ダメージを与えない。理由:斬り抜けた直後に硬直中の敵へ触れて被弾する理不尽を防ぐため
- 敵とプレイヤーは互いにすり抜ける(接触はダメージだけ)。敵は壁・岩には当たる。理由:踏み込みで敵を通過するため

## ふるまい(数値は全種共通。仮置き)
| 状態 | ふるまい |
|---|---|
| うろつき(出現時) | 追跡速度の半分で歩く。出現して最初の向きは主人公の方向±45°、以後は1〜2秒ごと、または壁・岩に当たったらランダムな向きに変える。理由:画面外に出た敵が画面へ入ってくるようにするため |
| 気づき | 主人公が視認距離 120px 以内に入ったら、0.5秒立ち止まり頭上に「!」を出す(コード描画) |
| 追跡 | 主人公へ直進する |
| 見失い | 追跡中に主人公が 260px より離れたら、うろつきへ戻る。画面の横半分(240px)より長くし、画面に見えている敵が追うのをやめないようにする |

- 斬られた敵は、被弾硬直のあと追跡に入る(斬られて気づかないのは不自然なため)
- 大群は出現した瞬間から追跡する。理由:決まったリズムで押し寄せる見せ場を残すため
- うろつき中に主人公から600px以上離れた敵は消す(魂は落とさず、撃破数にも数えない)。理由:遠くでうろつく敵が上限を埋め、圧力が消えるのを防ぐため

## 出現(数値は仮置き。試遊して調整する)
| 項目 | 値 |
|---|---|
| 出現位置 | 画面(カメラの映す範囲)の外側16pxの周上のランダムな点。フィールドの外・岩と重なる点は引き直す(フィールドの端で画面の外が無い辺には出ない) |
| 出現間隔・上限 | 下の区間表で決める。開始直後に1体目。上限は全種の合計で、上限の間は出現を見送る |
| 種類の選び方 | 出現のたびに、出現を始めている種類から重みで抽選する。重みは 小鬼6・赤鬼3・青鬼2・弓鬼2 |
| 出現を始める時刻 | 小鬼0秒・赤鬼60秒・弓鬼120秒・青鬼180秒。理由:序盤は小鬼で慣れ、後半ほど「どれから斬るか」の判断を増やすため |

### 区間
| 区間 | 出現間隔(区間の始め → 終わりへ直線的に) | 同時に出ている上限 |
|---|---|---|
| 0:00–1:00 導入 | 1.5 → 1.0秒 | 30 |
| 1:00–3:00 中盤 | 1.0 → 0.5秒 | 60 |
| 3:00–4:30 終盤 | 0.5 → 0.35秒 | 90 |
| 4:30–5:00 最後 | 0.3秒 | 100 |

理由:5分を同じ調子で押し続けると単調になるので、区間ごとに密度の段を付けるため。

### 大群
- 1:30・2:30・3:30・4:30 に、小鬼12体を一列(16px間隔、辺の中央ぞろえ)で出す。場所は画面の4辺のうち外側にフィールドが最も広く残っている辺の外側16px。列がフィールドからはみ出す分は内側へ詰める
- 大群は同時に出ている上限に数えず、上限でも出す
- 理由:「群れを一直線にまとめて斬る」一閃の見せ場を、決まったリズムで作るため

## ボス:大鬼
残り時間が0になった瞬間、大群と同じ辺の外側16pxに1体出る。最初から追跡し、見失わず、遠くても消えない。倒せばクリア。
理由:5分の終わりに、一閃で決める山場を作るため。

### 突進
| 項目 | 値 |
|---|---|
| 始める条件 | 追跡中に主人公が 140px 以内、前の突進から4秒以上 |
| 予告 | 0.8秒止まり、主人公の方向へ突進の線を赤く描く(向きは予告の始めに決める) |
| 突進 | 予告の向きへ 220px を 0.45秒。壁・岩に当たれば止まる |
| 隙 | 突進の後 1.0秒止まる |

- 予告中・隙の間も斬れる。被弾しても突進と予告は中断しない(被弾硬直は追跡中だけ)。理由:予告を見て横へ避け、隙に一閃を入れる読み合いにするため
- 大鬼が出ている間も通常の出現は続ける。間隔1.0秒・上限30。大群は出さない。理由:取り巻きを一閃の通り道に入れる判断を残しつつ、大鬼を見失わない密度にするため
