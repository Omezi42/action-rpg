# 9. 画面の流れ・記録

## 流れ
タイトル(→ 修行)→ 挑戦 → 結果 → (もう一度 / タイトルへ)。ゲームを起動するとタイトルから始まる。

## タイトル
- ゲーム名・「居合ボタンで始める」・最高記録・操作の一行説明を出す(コード描画)
- 居合ボタンで挑戦を始める。Tab(パッドは上ボタン)で修行(8章)を開く。Escでゲームを終える(Web版では終えず、操作の説明にも出さない。理由:ブラウザのゲームは終了できず、止めると画面が固まるため)
- 手持ちの武功を出す
- 開いてから0.3秒は入力を受けない。理由:結果画面から戻ったときの押しっぱなしで始まるのを防ぐため

## 結果
- 画面を止め、ゲームオーバー / クリア・生存時間・撃破数・到達レベル・最多人斬り(3章)・得た武功(8章)を出す。記録を更新した項目には「新記録」を付ける
- 居合ボタンでもう一度、Escでタイトルへ。開いてから0.5秒は入力を受けない。理由:斬っている最中に倒れたとき、連打で結果を読み飛ばさないため

## 最高記録
| 項目 | 内容 |
|---|---|
| 最長生存 | 生存時間の最大(クリアした挑戦は大鬼を倒した時刻) |
| 最多撃破 | 1回の撃破数の最大 |
| 最高レベル | 到達レベルの最大 |
| 最多人斬り | 1回の踏み込みで倒した数(3章)の最大 |
| クリア回数 | 大鬼を倒した回数 |
| 挑戦回数 | 結果まで進んだ回数 |

- 挑戦が終わった瞬間に保存する(`user://records.cfg`)。ファイルが無い・読めないときは全項目0から始める

## 修行
- 武功と修行の段階は `user://progress.cfg` に保存する(最高記録とは別のファイル)。ファイルが無い・読めないときは0から始める
- 買ったとき・戻したとき・挑戦が終わったときに保存する
