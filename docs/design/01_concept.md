# 1. コンセプト・範囲

- 見下ろし2Dの**居合サバイバー**。主人公は1〜2頭身のちびサムライ。四方から押し寄せる鬼の群れを居合で斬り抜け、制限時間まで生き残る
- 核の動詞は **居合切り**:溜めて、離すと自分ごと一直線に踏み込み、通過線上の敵を斬り抜ける。攻撃は自動にしない。理由:溜めと離すタイミングの判断がこのゲームの面白さだから
- 一番の気持ちよさは「群れを一直線にまとめて斬る」こと。居合の手触り(溜めの緊張 → 踏み込みの速さ → 斬り抜けた後の間)を優先する
- 1回の挑戦は短く完結させる(長さは未定。M2の結果で決める)

## M1(完了)
1画面の試作場で、移動・居合・敵1種(小鬼)・HP・ゲームオーバー→再開を動かす。理由:手触りを先に決めてから広げるため。

## M2(検証)
固定の1画面アリーナで、小鬼が時間とともに増えながら湧き続け、60秒生き残ればクリア。レベルアップ・強化は作らない。
理由:まず「居合で群れを斬るのが楽しいか」だけを確かめるため。
