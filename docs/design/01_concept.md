# 1. コンセプト・範囲

- 見下ろし2Dの**居合サバイバー**。主人公は1〜2頭身のちびサムライ。四方から押し寄せる鬼の群れを居合で斬り抜けて5分を生き残り、最後に現れる大鬼を斬ればクリア
- 核の動詞は **居合切り**:溜めて、離すと自分ごと一直線に踏み込み、通過線上の敵を斬り抜ける。攻撃は自動にしない。理由:溜めと離すタイミングの判断がこのゲームの面白さだから
- 一番の気持ちよさは「群れを一直線にまとめて斬る」こと。居合の手触り(溜めの緊張 → 踏み込みの速さ → 斬り抜けた後の間)を優先する
- **1回の挑戦は5分**。理由:居合は1回ごとに集中が要るので、短く完結させて繰り返し遊ばせるため
- 強化(8章)は居合と体を伸ばすものだけ。自動で攻撃する武器は足さない。理由:攻撃は自動にしないという核を守るため

## M1(完了)
1画面の試作場で、移動・居合・敵1種(小鬼)・HP・ゲームオーバー→再開を動かす。理由:手触りを先に決めてから広げるため。

## M2(完了)
固定の1画面アリーナで60秒生き残る。「居合で群れを斬るのが楽しいか」を確かめた。

## M3(完了)
固定の1画面アリーナで5分生き残る。レベルアップによる強化(8章)と、区間・大群による難しさの曲線(5章)を入れる。
理由:成長の手応えと、5分を通した緩急が面白さになるかを確かめるため。

## M4
広いフィールド(3×3画面)で5分生き残る。カメラは主人公を追う(6章)。
理由:壁・岩を使って群れを並べる、逃げ道を選ぶといった「どこで戦うか」の判断が面白さになるかを確かめるため。

## M5
タイトル → 5分の挑戦 → 大鬼 → 結果 → 再挑戦の一巡を作り、最高記録を残す。効果音をコードで合成して鳴らす(10章)。
理由:1回の挑戦に始まりと山場と終わりを付け、遊びとして完結させるため。

## M6
新しい挙動を持つ強化(斬痕・残心。8章)と、離れて矢を撃つ弓鬼(5章)を足す。
理由:挑戦ごとに育ち方と斬る順番が変わり、繰り返し遊ぶ理由を作るため。

## M8
まとめて斬った数の表示(3・6章)、途中の山場になる精鋭鬼と巻物(5・8章)、奥義と挙動の強化の追加(8章)を入れる。
理由:一番の気持ちよさを数で見せ、5分の途中に目標を置き、狙う奥義で育て方が変わるようにするため。

## M9
挑戦で得た武功を持ち越し、タイトルの修行画面で挑戦をまたぐ強化を買う(8章)。
理由:負けた挑戦にも次へつながる手応えを残し、挑戦の外にももう一度挑む理由を作るため。
