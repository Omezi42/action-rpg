# 2. 操作

| 操作 | キーボード+マウス | キーボードのみ | パッド |
|---|---|---|---|
| 移動(8方向) | WASD | WASD / 矢印 | 左スティック / 十字 |
| 居合(押す・長押し・離す) | 左クリック | J / Space | 下ボタン(Aの位置) |
| 居合の狙い | カーソルの方向 | 移動キーの向き | 左スティックの向き |
| ポーズ | Esc / P | Esc / P | Start |
| 強化カードを選ぶ(8章) | カードをクリック / 1・2・3 | 移動キーで選び居合で決定 / 1・2・3 | 左右で選び下ボタンで決定 |
| カードを引き直す / 封じる(8章の修行) | R / F | R / F | 左ボタン / 上ボタン |
| 修行を開く(タイトル) | Tab | Tab | 上ボタン |
| 修行を買う・全部戻す・閉じる | 項目をクリック / R / Esc・P | 上下で選び居合で買う / R / Esc・P | 上下で選び下ボタン / 左ボタン / Start |

- ポーズにPも割り当てる。理由:ブラウザの全画面ではEscが全画面の解除に取られ、ゲームに届かないため
- 通常の移動速度は 80px/秒。理由:小鬼の追跡(50px/秒)から歩いて離れられ、踏み込みとの速度差が際立つため
- 向きは最後に入力した方向(8方向)。居合の踏み込み方向もこの向き
- **マウスの狙い**:構え中は、押した瞬間から主人公から見たカーソルの方向へ踏み込む(抜き打ちも同じ)。向きは360度自由。
  カーソルが主人公から8px未満の間は今の向きのまま。理由:斬りたい場所を直接指せるほうが直感的で、群れを一直線に並べる角度も作れるため
- カーソルが向きを決めるのは構え中だけ。通常移動中の向きは移動キーで決める
- 見た目の向きは4方向(下・上・右・左)。斜めは横向きの絵で表す
