# 10. 効果音・BGM

## 音の出どころ
- 効果音もBGMも素材ファイル(`assets/audio/`)で鳴らす。素材の無い名前だけ、起動時にコードで合成した音で鳴らす
  (矩形波・三角波・ノイズに音程の変化と減衰を付ける)。理由:合成音で手触りを確かめた名前を、そのまま素材へ差し替えられるため
- 素材は再配布してよいもの(CC0 / CC-BY)に限る。理由:リポジトリを公開の場に置くため
- CC-BY の素材はタイトル画面の下端に1行でクレジットを出し、`assets/audio/CREDITS.md` に出典を書く
- 1つの名前に複数の候補を持たせ、鳴らすたびにランダムに選び、音程を少し揺らせる。理由:斬撃が続いても単調にしないため

## 効果音
| 名前 | 鳴る時 | 音の狙い |
|---|---|---|
| 段階 | 溜めが壱・弐へ上がった瞬間 | 短い高い音。弐は壱より高い |
| 一閃受付 | 参へ上がった瞬間(一閃の受付が始まる) | 澄んだ高音 |
| 抜き | 踏み込みが始まった瞬間 | 刀を振る風切り |
| 斬撃 | 敵に当たった瞬間 | 斬る音 |
| チン | 一閃の納刀 | 刀を鞘に納める音 |
| 被弾 | 主人公が被弾した瞬間 | 鈍い打撃 |
| 魂 | 魂を拾った瞬間(0.05秒に1回まで) | 小さな高い音 |
| レベルアップ | レベルアップ画面が開いた瞬間 | 上がる音 |
| 大鬼出現 | 大鬼が出た瞬間 | 重い鐘 |
| 大鬼予告 | 大鬼が突進の予告を始めた瞬間 | 低い警告音 |
| 大鬼撃破 | 大鬼を倒した瞬間 | 重い鐘 |
| 矢 | 弓鬼が矢を放った瞬間 | 弓の弦の音 |
| 決定 | タイトル・結果・カードで決めた瞬間 | 短い音 |
| カーソル | カード・修行・音量で選ぶ項目を動かした瞬間 | 決定より小さく短い音 |
| 購入 | 修行で買った瞬間 | 硬貨の音 |
| 人斬り | 「N人斬り」が出た瞬間 | 短い高音。一閃のときはチンに任せて鳴らさない |
| 精鋭出現 | 精鋭鬼が出た瞬間 | 大鬼出現より軽い鐘 |
| 巻物 | 巻物を拾った瞬間 | 大きく上がる音 |
| 返し | 燕返しの斬り返しが始まった瞬間 | 抜きより高い風切り |
| 弾き | 盾鬼が居合を盾で弾いた瞬間 | 刀同士がぶつかる金属音 |
| ゲームオーバー / クリア | 結果画面が開いた瞬間 | 短いジングル |

- 同じ音が同時に鳴りすぎないよう、同時発音は8つまで(古いものから止める)

## BGM
| 場面 | 曲 |
|---|---|
| タイトル(修行を含む) | 和楽器の静かなループ |
| 挑戦(大鬼が出るまで) | 太鼓のループ |
| 大鬼戦 | 太鼓と琴の速い曲 |
| 結果 | 鳴らさない(ジングルだけ) |

- 場面が変わったら0.5秒で次の曲へ切り替える。同じ曲のままなら頭から鳴らし直さない
- 時間が止まっている間(ポーズ・レベルアップ画面)はBGMを下げる

## 音量
- BGM と効果音の音量をそれぞれ 0〜10 で変えられる(既定は8)。0 は無音
- ポーズ画面で変える:上下で項目を選び、左右で値を変える。変えた瞬間に効果音で確かめられるよう、効果音の音量を変えたらカーソルの音を鳴らす
- `user://settings.cfg` に保存する。ファイルが無い・読めないときは既定値
