# 6. 画面・カメラ・UI

- 内部解像度 480×270、整数倍拡大(既定 ×4 = 1920×1080)。ピクセルの補間なし

## フィールドとカメラ
| 項目 | 値 |
|---|---|
| フィールド | 1440×810(3×3画面)。外周が壁。主人公は中央から始める。理由:壁で止まる・岩で群れを分ける地形の駆け引きを残しつつ、5分で迷わない広さにするため |
| 岩 | 12〜16個を手で配置して固定する。開始地点の半径80pxは空ける。理由:配置を覚えて地形を使えるようにするため |
| カメラ | 主人公を中心に追う。フィールドの端で止まり、壁の外は映さない。位置は整数ピクセルにそろえる |
| 構え中のカメラ | 主人公と予告線の先端の中点へ0.15秒かけて寄せる。踏み込みが始まったら0.3秒かけて主人公へ戻す。理由:最大の踏み込み(深踏み5段で256px)は画面の縦半分(135px)を超え、中心のままでは予告線の先が見えないため |
| 床 | 32px格子の淡い市松模様(コード描画)。理由:スクロールしていると分かるようにするため。背景の絵が届いたら置き換える |

- 画面外の敵を示す矢印・ミニマップは出さない。理由:3×3画面なら無くても迷わないため

## UI
- HPは左上にハート3個(コード描画)
- 右上にレベル・残り時間(分:秒)・撃破数を出す。残り時間にするのは、5分ではゴールまでの距離が見えている方が粘れるため
- 上端に経験値バー(次のレベルまでの溜まり具合、コード描画)
- レベルアップ画面:画面を暗くし、強化カード3枚を横に並べる。カードには名前・今の段階 → 次の段階・効果を書く(コード描画)
- 溜め段階は主人公の頭上に小さなゲージ(コード描画)で出す。構え中は踏み込む線を足元から点線で予告する(コード描画)
