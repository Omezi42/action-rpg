# 6. 画面・カメラ・UI

- 内部解像度 480×270、整数倍拡大(既定 ×4 = 1920×1080)。ピクセルの補間なし
- 1画面固定カメラのアリーナ。外周が壁、中央付近に障害物(岩)を数個。広いフィールド・スクロールは未定
- HPは左上にハート3個(コード描画)
- 右上に経過時間 / 制限時間と撃破数を出す
- 溜め段階は主人公の頭上に小さなゲージ(コード描画)で出す。構え中は踏み込む線を足元から点線で予告する(コード描画)
- 画面の上端に経験値のバー、その左にレベル(「Lv3」)を出す(コード描画)
- 強化の3択は画面中央に3枚の札(コード描画)で出し、名前・効果・「今の段 → 次の段 / 上限」を載せる。選んでいる札は枠を明るくする
- 経験値の玉は小さな水色の菱形(コード描画)
