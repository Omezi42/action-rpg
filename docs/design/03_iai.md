# 3. 居合切り

## 流れ
1. **構え(溜め)**:居合ボタンを押している間、納刀のまま腰を落とす。その場に止まり、向きだけ変えられる(マウスはカーソルの方向を狙う。2章)
2. **抜き(踏み込み)**:離すと向きの方向へ高速で一直線に移動し、通過線上の敵すべてに当たる
3. **納刀**:止まった位置で刀を納める短い硬直。この間は操作できない

## 溜め段階
| 段階 | 到達する押し時間 | 踏み込み距離 | 踏み込み時間 | 威力 |
|---|---|---|---|---|
| 抜き打ち(短押し) | 0.15秒未満 | 16px | 0.08秒 | 1 |
| 壱 | 0.15秒 | 48px | 0.12秒 | 2 |
| 弐 | 0.55秒 | 96px | 0.16秒 | 3 |
| 参 | 1.0秒 | 160px | 0.22秒 | 4 |
| **一閃** | 参に到達してから0.15秒以内に離す | 160px | 0.22秒 | 8 |

- 構え中は踏み込む線を地面に点線で予告する。長さは今離したときの踏み込み距離で、一閃の受付中は金色になる
- 抜き打ちは溜めずに出せる近距離の一太刀。連打で出し続けられる(納刀硬直は短い)
- 段階が上がる瞬間に光と音(10章)で知らせる。一閃の受付中は刀身が強く光る
- 参のまま押し続けると一閃の受付は終わり、参のまま保持する。理由:「最大溜めで待つ」より「最大溜めの瞬間に抜く」を気持ちよくするため

## 移動・硬直・無敵
| 項目 | 値 |
|---|---|
| 構え中の移動 | しない(向きのみ変えられる)。理由:足を止めて狙いを定める居合の構えを手に感じさせるため |
| 納刀硬直(抜き打ち) | 0.10秒 |
| 納刀硬直(壱〜参・一閃) | 0.25秒 |
| 踏み込み中の無敵 | あり(敵に触れてもダメージを受けない) |
| 構え中・納刀中の無敵 | なし |

- 踏み込み中に壁に当たったらその場で止まり、納刀へ移る
- 1回の踏み込みで同じ敵に当たるのは1度だけ
- 敵に当たるたびに短いヒットストップ(0.04秒)を入れる

## 一閃の演出
斬り抜けた敵は、納刀の「チン」と同時にまとめて倒れる(ダメージ判定自体は通過時に入る。倒れる見た目だけを納刀まで遅らせる)。
