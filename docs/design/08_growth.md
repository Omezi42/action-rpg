# 8. 成長

## 魂とレベル
| 項目 | 値 |
|---|---|
| 魂 | 敵が倒れた位置に落ちる。経験値は敵ごと(5章) |
| 拾い方 | 主人公の半径24pxに入った魂は吸い寄せられ(毎秒240px)、4px以内で拾う |
| 踏み込み中 | 半径24pxに入った魂をその場で拾う。理由:斬る線と拾う線を重ね、一直線に抜ける気持ちよさを増やすため |
| 次のレベルまでに要る経験値 | 5 + 2×(今のレベル−1)。レベル1から始まる。5分でおよそ15回上がる想定 |
| 魂が消えるまで | 消えない。画面に残るのは200個まで。超えたら古いものから拾ったことにして消す |

## レベルアップ
- 経験値が足りた瞬間にゲームを止め、強化カードを3枚から1枚選ぶ(操作は2章)。一度に複数上がったら、選ぶたびに次の3枚を出す
- 画面が出てから0.3秒は選べない。理由:構えのボタンを押したままレベルが上がったとき、誤って選ぶのを防ぐため
- 構えの途中でレベルが上がったら、選び終えた後は構えを解いた状態から再開する。ボタンは一度離すまで効かない。理由:カードを選んだクリックで踏み込みが出るのを防ぐため
- カードは最大まで取っていない強化から重ならないように無作為に選ぶ。残りが3種より少なければその数だけ出し、すべて最大なら「回復」だけを出す

## 強化(各5段階まで。数値は仮置き)
| 強化 | 1段ごとの効果 |
|---|---|
| 早抜き | 各溜め段階に届く時間 −10%(元の時間に対して) |
| 深踏み | 踏み込み距離 +12%(踏み込み時間は変えない) |
| 剛刃 | 壱以上(一閃を含む)の威力 +1 |
| 見切り | 一閃の受付時間 +0.04秒 |
| 韋駄天 | 移動速度 +8% |
| 頑健 | 最大HP +1(半ハート分)。取ったときに1回復する |
| 回復(すべて最大の後だけ) | HP +2。段階なし |

- 新しい挙動(衝撃波など)を持つ強化はM3では作らない。理由:まず数値の強化だけで成長の手応えが出るかを確かめるため
