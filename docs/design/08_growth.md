# 8. 成長

## 魂とレベル
| 項目 | 値 |
|---|---|
| 魂 | 敵が倒れた位置に落ちる。経験値は敵ごと(5章) |
| 拾い方 | 主人公の半径24pxに入った魂は吸い寄せられ(毎秒240px)、4px以内で拾う |
| 踏み込み中 | 半径24pxに入った魂をその場で拾う。理由:斬る線と拾う線を重ね、一直線に抜ける気持ちよさを増やすため |
| 次のレベルまでに要る経験値 | 5 + 2×(今のレベル−1)。レベル1から始まる。5分でおよそ15回上がる想定 |
| 魂が消えるまで | 消えない。フィールドに残るのは200個まで。超えたら古いものから拾ったことにして消す |

## レベルアップ
- 経験値が足りた瞬間にゲームを止め、強化カードを3枚から1枚選ぶ(操作は2章)。一度に複数上がったら、選ぶたびに次の3枚を出す
- 画面が出てから0.3秒は選べない。理由:構えのボタンを押したままレベルが上がったとき、誤って選ぶのを防ぐため
- 構えの途中でレベルが上がったら、選び終えた後は構えを解いた状態から再開する。ボタンは一度離すまで効かない。理由:カードを選んだクリックで踏み込みが出るのを防ぐため
- カードは最大まで取っていない強化から重ならないように無作為に選ぶ。残りが3種より少なければその数だけ出し、すべて最大なら「回復」だけを出す

## 強化(各5段階まで。数値は仮置き)
| 強化 | 1段ごとの効果 |
|---|---|
| 早抜き | 各溜め段階に届く時間 −10%(元の時間に対して) |
| 深踏み | 踏み込み距離 +12%(踏み込み時間は変えない) |
| 剛刃 | 壱以上(一閃を含む)の威力 +1 |
| 見切り | 一閃の受付時間 +0.04秒 |
| 韋駄天 | 移動速度 +8% |
| 頑健 | 最大HP +1(半ハート分)。取ったときに1回復する |
| 回復(すべて最大の後だけ) | HP +2。段階なし |

## 挙動の強化(各3段階まで)
| 強化 | 効果 | 1段ごと |
|---|---|---|
| 斬痕 | 壱以上(一閃を含む)で斬り抜けた線に斬撃が残り、触れた敵に威力1で当たる(同じ敵には1度だけ) | 残る時間 +0.3秒 |
| 残心 | 壱以上(一閃を含む)の踏み込みが止まった瞬間、その位置を中心に衝撃波が広がり、範囲の敵に威力2で当たる | 半径 +16px |
| 燕返し | 壱以上(一閃を含む)の踏み込みが止まってから0.3秒以内に居合を押すと、納刀を取り消し、来た方向へ0.12秒で斬り返す。威力2 | 距離 +32px(1段目は32px) |
| 影縫い | 主人公の踏み込み・燕返しで斬られて生き残った敵は、被弾硬直が影縫いの時間になる | 時間 +0.4秒(1段目は1.0秒) |

- 斬痕・残心の当たりにはヒットストップを入れない。理由:一閃の止めの手応えを薄めないため
- 斬痕・残心で倒した敵は、一閃の踏み込み中でもその場で倒れる(倒れる見た目を遅らせるのは踏み込みの当たりだけ)
- 理由:数値の強化に加えて、踏み込む位置と止まる位置の選び方が変わる強化を入れ、挑戦ごとに戦い方を変えるため

### 燕返し
- 斬り返しは踏み込みと同じ扱い:無敵・魂の即取得・ヒットストップあり・壁で止まる・同じ敵には1度だけ当たる
- 1回の踏み込みにつき1回。斬り返しからは返せない。斬り返しの後は壱以上と同じ納刀(0.25秒)に入る
- 斬り返しでは斬痕・残心を出さない。理由:強化どうしが連鎖して際限なく当たりが増えるのを防ぐため
- 押したまま斬り返しの納刀が終わったら、そのまま構えに入る(納刀中に押した居合と同じ)
- 理由:群れを抜けた直後に同じ群れをもう一度斬る、一往復の居合を作るため

### 影縫い
- 斬痕・残心の当たりでは止まらない。理由:置いておくだけで群れを止め続けるのを防ぐため
- 大鬼と、跳んでいる赤鬼には効かない。理由:大鬼の山場を崩さないため・跳んでいる赤鬼は斬れないため
- 止まっている敵の足元に影(コード描画)を出す
- 理由:斬り残した硬い敵に二の太刀を入れる時間を作り、青鬼や精鋭鬼への攻め方を変えるため

## 巻物
- 精鋭鬼(5章)が落とす。消えない。主人公の半径16px以内に入ったら拾う(踏み込み中も)
- 拾った瞬間にゲームを止め、レベルアップと同じ画面(6章)で3枚から1枚を選ぶ。誤操作防止・構えの扱いはレベルアップと同じ
- 3枚の中身:
  1. 2枚は、条件を満たしてまだ取っていない奥義を優先して入れ、残りを最大でない挙動の強化から重ならないように無作為に選ぶ。足りなければその数だけ出す
  2. 1枚は必ず「全回復」(HPを最大まで戻す)
- 理由:奥義を狙う目標と、途中で立て直す機会を同じ選択に並べるため

## 奥義(各1回)
挙動の強化を3段にし、対になる数値強化を5段にすると、巻物に出るようになる。レベルアップのカードには出ない。

| 奥義 | 条件 | 効果 |
|---|---|---|
| 焔痕 | 斬痕3+剛刃5 | 斬痕の威力が2、残る時間が2倍 |
| 大残心 | 残心3+深踏み5 | 衝撃波が0.3秒後にもう1回、同じ位置・半径・威力で広がる |
| 燕返し・極 | 燕返し3+早抜き5 | 斬り返しの距離が、元の踏み込みの距離と同じになる |
| 影縫い・極 | 影縫い3+見切り5 | 踏み込み・燕返しで斬った線の左右16px以内にいる敵も、斬られていなくても同じ時間止まる(予告・攻撃は取り消す) |

- 理由:同じ数値強化を積むだけにせず、どの奥義を狙うかで挑戦ごとに育て方を変えるため。どれも居合の挙動を変えるもので、自動攻撃は足さない
