# 8. 成長(1回の挑戦の中)

撃破で経験値を集め、レベルアップのたびに3択で居合を強化する。理由:強化の組み合わせで毎回違う居合になり、繰り返し遊ぶ理由を作るため。
強化はその挑戦の間だけ有効で、やり直すと最初からになる。

## 経験値の玉
| 項目 | 値 |
|---|---|
| 落とす数 | 倒した敵1体につき1個、倒れた場所に落とす |
| 玉の点数 | 小鬼1・赤鬼1・青鬼3 |
| 回収範囲 | 主人公の足元から半径16px。範囲に入った玉は主人公へ吸い寄せる(240px/秒) |
| 回収 | 吸い寄せた玉が足元から4px以内に届いたら回収する |

- **踏み込み中も回収する**。理由:斬り抜けた線上の玉をまとめて拾えると、居合と回収がつながるため
- 玉は時間では消えない

## レベルアップ
- レベル1から始まる。次のレベルまでに要る点数は `5 + 3 ×(今のレベル − 1)`(5, 8, 11, …)。余った点数は持ち越す
- レベルが上がったらゲームを止め、強化の3択を出す。候補は上限に達していない強化からランダムに3つ(重複なし)
- 候補が3つに満たないときは「手当(HPを2回復)」を1枚足す
- 一度に複数レベル上がったら、3択を続けて出す
- 3択を出してから0.4秒は選べない。理由:抜き打ちの連打中に出たとき、押し続けた入力で勝手に選ばれるのを防ぐため

## 強化(数値は仮置き。試遊して調整する)
| 名前 | 効果 | 上限 |
|---|---|---|
| 研ぎ | 全段階の威力+1 | 3 |
| 早抜き | 溜めの到達時間 −15%(重ねると掛け算) | 3 |
| 残心 | 一閃の受付 +0.1秒 | 2 |
| 遠間 | 踏み込み距離 +20%(踏み込み時間は変えない) | 2 |
| 斬痕 | 斬り抜けた線に斬撃が残り、触れた敵に威力1。残る時間は0.5秒、1段上げるごとに +0.3秒。1本の斬痕が同じ敵に当たるのは1度だけ | 3 |
| 韋駄天 | 移動速度 +10% | 2 |
| 吸気 | 玉の回収範囲 +50% | 2 |

- 強化は `.tres` を1つ足せば候補に加わる。既にある能力値を足す・掛けるだけの強化(表の斬痕以外)は、コードを変えずに増やせる
